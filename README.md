```markdown
# YouTube Video Downloader
```
A simple GUI application to download YouTube videos in the highest available quality.

## Features
- Downloads videos in MP4 format  
- Simple graphical interface  
- Error handling for invalid URLs  
- Progress notifications  

## Requirements
- Python 3.6+  
- Tkinter (usually included with Python)  
- pytubefix library  

## Installation
1. Install the required packages:
   ```bash
   pip install pytubefix
   ```

2. Clone this repository or download the `main.py` file.

## Usage
1. Run the application:
   ```bash
   python main.py
   ```

2. In the GUI:
   - Enter a valid YouTube URL in the "LINK" field  
   - Specify a download path in the "PATH" field  
   - Click "DOWNLOAD" to start the download  
   - Use "EXIT PROGRAM" to close the application

## Troubleshooting
- Update pytubefix: 
```bash 
  pip install --upgrade pytubefix
```
